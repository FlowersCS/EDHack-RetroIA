# 📖 Manual de Usuario - EDHack IA

## 👋 Bienvenido a EDHack IA

EDHack IA es un sistema de evaluación automática de escritura que utiliza inteligencia artificial para analizar textos de estudiantes y generar retroalimentación detallada.

---

## 🎯 ¿Qué hace el sistema?

### Para Estudiantes 📝
- Recibe tu texto escrito en formato PDF
- Analiza ortografía, gramática, coherencia y estructura
- Proporciona retroalimentación constructiva
- Sugiere áreas de mejora específicas

### Para Docentes 👩‍🏫
- Genera evaluación automática inicial
- Permite revisión y edición de la retroalimentación
- Crea documentos Google Docs editables
- Produce reportes técnicos detallados

### Para Familias 👨‍👩‍👧‍👦
- Proporciona reportes comprensibles para padres
- Sugiere actividades de apoyo en casa
- Explica el progreso del estudiante

---

## 🚀 Cómo usar el sistema

### Paso 1: Subir PDF 📄

1. **Preparar el documento**
   - Asegúrate de que el texto esté en formato PDF
   - El archivo debe contener texto extraíble (no solo imágenes)
   - Tamaño máximo: 16MB

2. **Subir archivo**
   - Arrastra el PDF a la zona de carga
   - O haz clic para seleccionar archivo
   - Espera confirmación de carga exitosa

3. **Verificar extracción**
   - El sistema mostrará una vista previa del texto extraído
   - Verifica que el contenido sea correcto

### Paso 2: Evaluación con IA 🤖

1. **Proceso automático**
   - La IA analiza el texto según 6 criterios:
     - **Ortografía** (20%): Uso correcto de reglas ortográficas
     - **Gramática** (20%): Estructura gramatical y sintaxis
     - **Coherencia** (25%): Lógica y flujo de ideas
     - **Cohesión** (15%): Conexión entre párrafos
     - **Vocabulario** (10%): Riqueza y precisión
     - **Estructura** (10%): Organización del texto

2. **Resultado de evaluación**
   - Puntuación total de 0-100
   - Nivel sugerido (Principiante/Intermedio/Avanzado)
   - Lista de fortalezas identificadas
   - Áreas de mejora específicas

3. **Documento Google Docs**
   - Se crea automáticamente un documento editable
   - Contiene la evaluación detallada
   - Enlace para acceso directo

### Paso 3: Revisión Docente 🎓

1. **Acceder al documento**
   - Hacer clic en "Abrir Documento Google Docs"
   - El documento se abre en nueva pestaña
   - Está listo para edición directa

2. **Revisar y editar**
   - Leer la evaluación generada por IA
   - Corregir puntuaciones si es necesario
   - Añadir comentarios personalizados
   - Ajustar observaciones específicas

3. **Tomar decisión**
   - **Aprobar**: Si la retroalimentación está correcta
   - **Revisar**: Si necesita correcciones adicionales de IA

### Paso 4: Reportes Finales 📊

Una vez aprobada la evaluación, se generan 3 reportes:

#### 📝 Reporte para Estudiante
- Lenguaje motivacional y accesible
- Enfoque en crecimiento personal
- Próximos pasos claros
- Celebración de fortalezas

#### 👨‍👩‍👧‍👦 Reporte para Familia
- Información comprensible para padres
- Sugerencias de apoyo en casa
- Actividades recomendadas
- Contexto del progreso del estudiante

#### 🎓 Reporte Técnico para Docente
- Datos detallados y estadísticas
- Recomendaciones pedagógicas
- Información del proceso de evaluación
- Registro para expediente académico

## 💡 Consejos para Mejores Resultados

### Para Preparar el PDF
- ✅ Usar texto digitalizado (no escaneado)
- ✅ Letra clara y legible
- ✅ Párrafos bien separados
- ✅ Estructura clara (introducción, desarrollo, conclusión)

### Para Docentes
- ✅ Revisar siempre la evaluación de IA
- ✅ Añadir contexto específico del estudiante
- ✅ Personalizar comentarios cuando sea necesario
- ✅ Considerar el nivel educativo del alumno

## 🎯 Criterios de Evaluación Detallados

### 📝 Ortografía (20%)
- Uso correcto de tildes
- Aplicación de reglas de escritura
- Ausencia de errores tipográficos
- Uso apropiado de mayúsculas

### 📚 Gramática (20%)
- Concordancia sujeto-verbo
- Uso correcto de tiempos verbales
- Estructura de oraciones
- Uso apropiado de conectores

### 🧠 Coherencia (25%)
- Desarrollo lógico de ideas
- Progresión temática clara
- Relación entre párrafos
- Mensaje central comprensible

### 🔗 Cohesión (15%)
- Uso de conectores apropiados
- Referencias claras (pronombres, sinónimos)
- Fluidez en la lectura
- Continuidad textual

### 📖 Vocabulario (10%)
- Variedad léxica
- Precisión en el uso de palabras
- Adecuación al contexto
- Riqueza expresiva

### 🏗️ Estructura (10%)
- Organización clara del texto
- Presencia de introducción, desarrollo y conclusión
- Párrafos bien delimitados
- Secuencia lógica de contenidos

## 🔍 Interpretación de Puntuaciones

| Puntuación | Calificación | Descripción |
|------------|-------------|-------------|
| 90-100 | Excelente 🌟 | Dominio avanzado de la escritura |
| 80-89 | Muy Bueno 👍 | Competencia sólida con aspectos menores a mejorar |
| 70-79 | Bueno ✅ | Nivel satisfactorio con oportunidades de crecimiento |
| 60-69 | Regular ⚠️ | Necesita trabajo en varias áreas |
| 0-59 | Necesita Mejora 📚 | Requiere apoyo significativo |

## 🚨 Qué hacer si algo no funciona

### El PDF no se puede cargar
- Verificar que sea un archivo PDF válido
- Comprobar que no exceda 16MB
- Asegurar que contiene texto (no solo imágenes)

### La evaluación tarda mucho
- Proceso normal: 30 segundos a 2 minutos
- Textos largos pueden tomar más tiempo
- No cerrar la ventana durante el proceso

### No se puede abrir Google Docs
- Verificar conexión a internet
- Asegurar que tienes cuenta de Google
- Intentar abrir el enlace en otra pestaña

### Los reportes no se generan
- Asegurar que se aprobó la evaluación
- Verificar que el proceso completó todos los pasos
- Intentar reiniciar desde revisión docente
